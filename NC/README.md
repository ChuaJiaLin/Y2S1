# Reflection

The Network Communications course provided valuable knowledge and practical experience in computer networking concepts, data communication principles, and Internet protocols based on the TCP/IP model. It established a strong foundation for understanding how modern communication systems operate and support digital connectivity.

Throughout the course, comprehensive understanding was developed across the different layers of the TCP/IP protocol stack, including the application, transport, network, link, and wireless network layers. These concepts were reinforced through lectures, laboratory exercises, tests, and project-based learning activities, ensuring both theoretical knowledge and practical application.

Practical exposure to networking tools such as Wireshark and Cisco Packet Tracer significantly enhanced technical skills in network analysis, packet inspection, subnetting, routing, and local area network (LAN) design. This hands-on experience improved the ability to analyse network traffic, troubleshoot connectivity issues, and design efficient network infrastructures.

In addition, the group project contributed to the development of teamwork, analytical thinking, problem-solving, and technical report writing skills. Designing and implementing a network solution based on a real-world case study encouraged collaboration, structured problem analysis, and effective communication of technical ideas.

The course also increased understanding of how networking technologies support Internet services, wireless communication, and modern computing environments. This highlights the importance of reliable and efficient communication systems in supporting various digital applications and services.

Overall, the course successfully enhanced both theoretical understanding and practical competency in computer networking and data communication technologies, while strengthening confidence in applying these skills in real-world scenarios.
